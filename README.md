# Retail Demand Forecasting & Inventory Intelligence System

## 📌 Project Overview
This project is designed to analyze retail sales, forecast product demand using Machine Learning, and provide insights into inventory management through an interactive dashboard.

## 🎯 Objectives
- Analyze retail sales data using Python and SQL.
- Perform data cleaning and Exploratory Data Analysis (EDA).
- Create features for demand forecasting.
- Predict product demand using Machine Learning.
- Visualize sales and inventory insights using Power BI and Streamlit.

## 🛠️ Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- SQLite
- Power BI
- Streamlit
- Git & GitHub

## 📊 Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. SQL Analysis
5. Feature Engineering
6. Machine Learning Model Training
7. Demand Prediction
8. Power BI Dashboard
9. Streamlit Web Application

## 🤖 Machine Learning
Models used:
- Random Forest Regressor
- Gradient Boosting Regressor

Random Forest Evaluation:
- MAE: 69.99
- RMSE: 89.85
- R² Score: 0.328

## 📈 Dashboard Features
- Total Units Sold
- Total Revenue
- Region-wise Sales
- Category-wise Sales
- Monthly Sales Trends
- Weather-wise Sales
- Promotion Analysis
- Interactive Filters

## 🚀 Streamlit Application
The Streamlit application provides:
- Region and Category filters
- Interactive sales charts
- Total Revenue and Units Sold metrics
- ML-based Demand Prediction

## ▶️ How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
